# Count-based PM2.5 paper reproduction audit

Scientific narratives: [English](narrative_en.md) and [Español](narrative_es.md).

`summary.json` contains the main findings; `methods.json` records analysis choices and software. `paper_claim_audit.csv` distinguishes recovered calculations, verified author-table contents, and results not testable with the recovered methods. `metadata/replication_pm/source_manifest.json` records official sources and file hashes. `validation.json` and `visual_review.json` record numerical and visual checks.

The cortex original is reproduced with 20 animals and four contrasts. Existing eight-animal cortex and seven-animal hypothalamus primary analyses are separate and are not overwritten. The hypothalamus fit is an explicit sensitivity without the unrecovered RUVg controls/factor count. Marker QC is descriptive and does not infer sample sex or remove animals.

From the repository root, with the project's analysis Python environment and R libraries available:

```sh
.venv-analysis/bin/python scripts/replicate_pm_papers.py --fetch-sources --refit
```

This downloads the official Zenodo author archive, GENCODE M13 annotation and JCI supplement if needed; it requires the repository's GEO study downloads and sample metadata. It independently reimplements the reviewed statistical steps rather than executing downloaded author code. The original 20-animal count fit and the unadjusted 11-animal hypothalamus fit are generated by `scripts/replicate_pm_papers.R`. R packages are resolved first from the repository's `.r-library`; fitted versions are recorded in `methods.json` and `R_session_info.txt`.

To rebuild comparison tables, figures and manifests from existing R model outputs:

```sh
.venv-analysis/bin/python scripts/replicate_pm_papers.py
```

`figure_manifest.json` provides English/Spanish captions, exact source tables and hashes for four figure families, each exported in PNG/SVG/PDF. The internal plot artwork is English. The figure families are:

- `cortex_replication_benchmark`: original/refit gene-level agreement and sensitivity to the analysis population.
- `cortex_multicondition_signature`: source-selected effects, exact set intersections and pointwise model intervals.
- `hypothalamus_method_sensitivity`: declared unadjusted reconstruction, all-animal patterns and method-dependent gene counts.
- `cortex_marker_qc`: observed Y-linked and Xist expression in every animal, without sex classification.

Large local fit objects and original publisher reading copies are ignored. Curated computed results and source URLs/hashes are public. The original author code/data is refetched from the cited deposit for rerunning. These results are computational reproduction with the same animals, not independent biological replication, new spatial measurements, or validation of a 3D simulation.
