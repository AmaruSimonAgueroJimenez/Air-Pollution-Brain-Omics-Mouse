Anatomy-mean μ credible intervals, known-section p posterior intervals and new-section p/count predictive intervals answer different questions. This analysis describes baseline detection using fixed priors and physical-section heterogeneity. It does not model PM2.5 responses, RNA magnitude, exposed cell types or new spatial resolution. There is one donor; sections are not animal replicates. Implementation validation and scientific diagnostics are reported separately.
