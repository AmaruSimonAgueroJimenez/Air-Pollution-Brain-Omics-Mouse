# Detección basal Beta-Binomial jerárquica

ACA:10 genes, 1,280 grupos observados corte×anatomía. Cobertura predictiva95% de conteos excluidos 97.9%; Brier 0.13725 frente a referencia regional 0.14051. Grupos de prueba solo con prior: 0; no se ajustan con datos excluidos. Diferencia máxima de media μ entre cuadrículas64×48 y96×64: 0.0002.

HY:10 genes, 1,860 grupos observados corte×anatomía. Cobertura predictiva95% de conteos excluidos 99.4%; Brier 0.09246 frente a referencia regional 0.03621. Grupos de prueba solo con prior: 790; no se ajustan con datos excluidos. Diferencia máxima de media μ entre cuadrículas64×48 y96×64: 0.0005.

Los intervalos creíbles de μ anatómica, la posterior de p de un corte ya medido y la predicción de p/conteos de un corte nuevo responden preguntas distintas. Este análisis describe detección basal con priors fijas y heterogeneidad entre cortes. No modela respuesta PM2.5, magnitud de RNA, tipos celulares expuestos ni nueva resolución espacial. Hay un donante; los cortes no son réplicas animales. Validación de implementación y diagnósticos científicos se informan por separado.
