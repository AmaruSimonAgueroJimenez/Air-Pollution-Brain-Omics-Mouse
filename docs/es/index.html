Introducción

Los cuatro estudios miden regiones, exposiciones y ensayos diferentes. Se analizan por separado y no se combinan en un único efecto de la contaminación. El atlas de referencia conserva las ubicaciones celulares y mide 1,122 genes mediante MERFISH, lo que aporta un contexto anatómico para determinadas señales regionales. No proporciona células individuales expuestas. Leer la introducción.

Metodología

El flujo clásico incluye comprobaciones de fuentes y muestras, distribuciones de conteos o señales, relaciones entre muestras y PCA, expresión diferencial con control de pruebas múltiples, estimación de tamaños de efecto y enriquecimiento funcional cuando las anotaciones génicas lo permiten. El ozono se reprocesa desde las lecturas originales. El modelo 3D utiliza dentro del hipotálamo un multiplicador regional específico para cada gen, derivado del tejido completo, y mantiene fijas las posiciones celulares de referencia. Leer la metodología.
