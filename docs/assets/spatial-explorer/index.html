Bayesian model of detection probability

The observed fraction is data. The modeled probability is a bounded 0–1 hierarchical beta-binomial estimate for this physical section and anatomy. It uses all cell classes and one donor; it does not estimate PM2.5 expression or add spatial resolution.

Evaluation on held-out physical sections

The current-section credible interval estimates its cell probability p using data from this section. The anatomical mean μ interval and the probability p interval for a new section have different targets; they appear separately below.
