Compare up to three genes using the same registered reference population. Detection and mean imaging count include zeros and are gene-specific assay summaries; their magnitude does not rank biological importance or exposure response. Each 3D reference/scenario pair uses its own shared color scale.

Independent animals, not atlas-cell replicates

Eight anterior cingulate cortex libraries support the exposure contrast: four PBS controls and four PM2.5 animals. These normalized RNA-seq counts have different units from imaging counts.

Source values

FDR refers to the original bulk Wald test. The alternative interval scenarios use the unshrunken coefficient ±1.96 SE; they are not confidence intervals for individual cells.

Model, anatomy, and limitations
  • Within ACA only: E_scenario = E_reference × 2^(bulk log₂FC). The central scenario uses the shrunken coefficient.
  • All cells receive the same gene-specific multiplier. The model preserves basal gradients and zeros; it does not identify cell-type-specific susceptibility or cell loss.
  • Outside the anterior cingulate cortex, the anatomical surface is context only. No exposure effect is assigned there.
  • The reference uses one registered hemisphere of adult male Zhuang-ABCA-2. No cells are mirrored, spatially interpolated, or treated as independent exposure replicates.
  • Axes use CCF distances in millimeters. Surface geometry is simplified for interaction; the measured molecular coordinates are retained.
  • The atlas is not a matched experimental control for the eight cortical animals; sample composition and source-quality questions remain. Exploratory genes remain labeled.
