The left view shows measured expression from the reference atlas. The right view multiplies those same cell values by a gene-specific regional effect from the hypothalamic bulk study. It is permanently labeled SIMULATED. Both views use the same cell positions, linked cameras, and a common color scale.

Start with Tll1. It is the only primary hypothalamic FDR hit measured in this panel. The central multiplier is approximately 0.428×, but its significance is sensitive to individual animals. The other measured genes remain available, with nonsignificant exposure estimates labeled exploratory and unreliable estimates kept reference-only.

Open the standalone viewer

Using the viewer

  1. Type a gene symbol and select Apply. All 1,122 measured panel genes are available.
  2. Rotate either scene; the other camera follows. Select Whole-brain context to see the anatomical surface surrounding the hypothalamus.
  3. Filter by cell class or hypothalamic substructure. Filtering changes the cells shown, not their expression values.
  4. Compare the central shrunken effect with the lower or upper pointwise group-effect scenario. These bounds are not individual-cell confidence intervals.
  5. Inspect the seven bulk-animal values below the scenes. The atlas cells do not increase the experimental sample size.

The optional common color cap uses the 99th percentile of positive reference/scenario values. Saturated colors do not discard values: actual values remain in hover and source files. Measured zeros are shown by default and can be hidden explicitly.

Tll1 has a positive measured imaging count in 667 of 37,811 cells (1.76%) in this reference. The remaining measured zeros dominate an all-cell view; a zero imaging count does not establish biological absence. The viewer reports the number of currently shown cells with positive measured counts. Hiding zeros is an explicit display filter and does not create additional observations.
