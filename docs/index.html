REPRODUCIBLE PUBLIC-DATA STUDY · FOUR INDEPENDENT EXPERIMENTS

How do regional brain expression profiles differ after PM2.5 or ozone exposure, and where are the affected genes normally expressed? This report separates the experimental contrasts from a spatial reference and an explicitly modeled PM2.5 scenario.

Introduction

The four studies measure different regions, exposures, and assays. They are analyzed separately rather than pooled into a single pollution effect. The reference atlas preserves cell locations and measures 1,122 genes by MERFISH, providing an anatomical setting for selected regional signals. It does not supply exposed single cells. Read the Introduction.

Methods

The classical workflow includes source and sample checks, count or signal distributions, sample relationships and PCA, differential expression with multiple-testing control, effect-size estimation, and functional enrichment where gene annotations are applicable. Ozone is reprocessed from the original reads. The 3D model uses one bulk gene-specific multiplier within the hypothalamus and keeps the reference cell positions fixed. Read the Methods.

Reproduce the papers, then examine the response structure

Original-study reproduction → compares the actual deposited code and gene tables with new fits. The original 20-sample cortex model recovers all four significant-gene sets exactly (109 / 1,205 / 1,222 / 639). Hypothalamus, miRNA, and ozone have explicit partial-reproduction boundaries. Cortex Y-linked signals also reveal a sample-quality question that numerical agreement cannot resolve.

Interactions and molecular panels → adds formal age/genotype response tests, covariance-aware effect intervals, individual-animal panels, a six-contrast GO enrichment matrix, and a gene-set overlap network. Eight age-response genes pass the within-family ozone test; one remains after joint correction across all three interaction-test families. This is secondary evidence from the same animals.

Each panel links to vector figures and source tables. Reproduction of a computation, biological interpretation, and the spatial simulation are identified separately throughout the report.

A measured reference beside an explicit simulation

Tll1 is the only primary hypothalamic FDR hit measured in this MERFISH panel. Its central regional multiplier is 0.428×. The viewer contains 1,122 measured genes, with reliable bulk effect estimates for 1,003 of them; nonsignificant genes are labeled exploratory.

A modeled scenario, not exposed spatial data. The atlas donor is not an experimental control for the seven bulk animals. A uniform regional multiplier does not identify which cell types respond, and it does not model cell loss, movement, or anatomical change.

## Reproduce the papers, then examine the response structure

[**Original-study reproduction →**](replication.qmd) compares the actual deposited code and gene tables with new fits. The original 20-sample cortex model recovers **all four significant-gene sets exactly** (109 / 1,205 / 1,222 / 639). Hypothalamus, miRNA, and ozone have explicit partial-reproduction boundaries. [**Interactions and molecular panels →**](advanced_results.qmd) adds formal age/genotype response tests, covariance-aware effect intervals, individual-animal panels, a six-contrast GO enrichment matrix, and a gene-set overlap network.
