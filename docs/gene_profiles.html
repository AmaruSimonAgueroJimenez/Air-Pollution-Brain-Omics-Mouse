Priority genes and their encoded products

Hypothalamus and anterior cingulate cortex: evidence, molecular functions, and spatial coverage

Analysis date

19 October 2026

Scientific priorities beyond one atlas gene

The analysis contains many regional expression findings. A gene’s availability in a targeted spatial panel is a separate property from its statistical evidence. We retain all 11 primary hypothalamic discoveries, the 20 strongest primary protein-coding cortex discoveries, and explicitly defined measured-panel shortlists. No gene is removed from the report because it lacks spatial measurements.

These are transparent, post-analysis priorities for interpretation and follow-up. Ranking by BH q does not establish biological importance, a therapeutic target, or a causal mechanism. The primary results and gene-level tests are unchanged. Rajagopalan et al. (2020) Zhang et al. (2025)

How genes were selected and annotated

The hypothalamic discovery list is the complete original Python BH < 0.05 set. Cortex priorities are the first 20 protein-coding genes ordered by primary BH q, then the documented tie-breaks. The spatial shortlists select the ten strongest eligible genes actually measured by MERFISH within each region. Hypothalamic measured genes after Tll1 remain exploratory; they are not relabeled as discoveries.

Official mouse gene annotations distinguish the original assay symbol, current official symbol, gene type and encoded product. Gene names link to the corresponding NCBI source; available protein records link to UniProt. A molecular function describes the annotated gene product. Differential RNA abundance does not itself measure protein abundance, enzyme activity, or a pathway’s activation.

Effects in the tables are unshrunken regional MLE log₂FC with pointwise 95% Wald intervals. BH q refers to the original primary test. The 3D central scenario uses the separately saved shrunken coefficient; the two estimates are not interchangeable.

```{python}
import json
import html
import pandas as pd
from IPython.display import Markdown, display
from _report_utils import ROOT, read_table, figure, show_table
p = read_table("gene_priorities", "prioritized_genes.tsv")
a = read_table("gene_priorities", "annotations.tsv").fillna("")
def gene_table(group, language):
    part = p.loc[p.selection_group.eq(group)].sort_values("selection_rank").copy()
    spanish = language == "es"
    headers = ["Gen y fuente", "Qué codifica", "Función molecular", "Efecto regional PM", "q de BH", "Panel espacial"] if spanish else ["Gene and source", "Encoded product", "Molecular function", "Regional PM effect", "BH q", "Spatial panel"]
    rows = []
    for r in part.to_dict("records"):
        e = lambda x: html.escape(str(x), quote=True)
        official = str(r.get("official_symbol", r["gene"]))
        gene = '<a href="' + e(r["source_url"]) + '" target="_blank" rel="noopener">' + e(r["gene"]) + '</a>'
        if official != str(r["gene"]):
            gene += '<br><small>' + ("Símbolo actual: " if spanish else "Current symbol: ") + e(official) + '</small>'
        product = e(r["protein_name_" + language])
        if pd.notna(r.get("uniprot_url")) and str(r["uniprot_url"]).startswith("https://"):
            product += '<br><a href="' + e(r["uniprot_url"]) + '" target="_blank" rel="noopener">UniProt</a>'
        role = e(r["function_" + language])
        effect = f'{r["log2FoldChange"]:+.2f}<br><small>' + ('IC 95%' if spanish else '95% CI') + f' [{r["CI95_lower"]:+.2f}, {r["CI95_upper"]:+.2f}]</small>'
        q = float(r["padj"])
        qtext = f"{q:.2e}" if q < .01 else f"{q:.3f}"
        measured = bool(r["atlas_measured"])
        spatial = ("Medido" if measured else "No medido") if spanish else ("Measured" if measured else "Not measured")
        if not bool(r["primary_significant"]):
            spatial += '<br><small>' + ("Efecto exploratorio" if spanish else "Exploratory effect") + '</small>'
        rows.append("<tr>" + "".join("<td>" + str(x) + "</td>" for x in [gene, product, role, effect, qtext, spatial]) + "</tr>")
    display(Markdown('<div class="table-scroll"><table class="table table-sm table-striped evidence-table gene-evidence-table"><thead><tr>' + "".join("<th>" + e(x) + "</th>" for x in headers) + "</tr></thead><tbody>" + "".join(rows) + "</tbody></table></div>"))
```
